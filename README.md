# Scholarise

> **Study smarter, not harder.** An Apple HIG-caliber educational AI study mobile application built with React, Vite, and Tailwind CSS.

---

## 🌟 Highlights

- **Apple Human Interface Guidelines Design**: Crafted with warm organic cream tones (`#FAF5ED`), Obsidian glass cards, crisp Plus Jakarta Sans typography, and fluid micro-interactions.
- **Complete Onboarding & Customization**:
  - Exam type selection (Upcoming, Regular, Assignments)
  - Multi-subject selection with custom subject support
  - Time commitment & study goal tuning
  - Comprehensive profile details (Name, Age, Email, Country Code & Phone)
  - Interactive syllabus upload with drag-and-drop support
  - Custom SVG Thinking Orb state transition
- **Daily Focus & Study Tracking**:
  - Active study sessions and subject breakdowns
  - Weekly study time analytics with 7-day progress bars
  - Dynamic daily streak tracker
- **Profile & Account Management**:
  - Interactive display name editor
  - Integrated Terms & Conditions and Academic Integrity policies
  - Silent, secure sign-out
- **Session Persistence**:
  - Automatically persists user session and preferences in `localStorage` across page reloads and browser restarts.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/divyansh-shandilya/scholarise.git
   cd scholarise
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
